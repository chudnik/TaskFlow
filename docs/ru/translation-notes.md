# Примечания к русской терминологии

> Источник: [английская документация](../README.md). Английская документация является канонической. При изменении поведения, команд или контрактов необходимо проверить обе языковые версии.

При проверке перевода кодовые блоки, HTTP routes, JSON fields, environment variables,
CTest/GoogleTest names и shell commands сопоставляются с английскими источниками
дословно. На 28 июля 2026 года различий в исполняемых примерах не обнаружено.

Для однозначного поиска по исходному коду и внешней документации следующие термины
намеренно оставлены на английском:

- API, WebSocket, endpoint, route и payload;
- access token, refresh token и JWT;
- replay, resume, delivery, readiness и health check;
- worker, job, outbox, lease и retry;
- smoke test, sanitizer, workflow и supply chain.

Русский текст объясняет смысл этих терминов при первом использовании. Новые термины
следует добавлять в этот список только тогда, когда перевод мешает сопоставлению с
кодом, протоколом или эксплуатационной командой.
