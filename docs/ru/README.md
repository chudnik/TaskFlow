# Документация TaskFlow на русском

> Источник: [README.md](../../README.md). Английская документация является канонической. При изменении поведения, команд или контрактов необходимо проверить обе языковые версии.

TaskFlow — модульный монолит на C++20 для многопользовательского управления задачами.

1. [Установка и разработка](setup.md) — зависимости, Conan, CMake, Docker Compose, миграции и тесты.
2. [Использование API](api.md) — аутентификация, проекты, задачи, комментарии и история.
3. [Протокол WebSocket](websocket-protocol.md) — подключение, события, подтверждения и replay.

## Правила перевода

- Английский документ, указанный в блоке «Источник», остаётся каноническим.
- Изменение поведения, команды, API или эксплуатационного контракта требует review обеих версий.
- Команды, пути, HTTP routes, JSON/SQL fields, environment variables и имена тестов не переводятся.
- Русский текст объясняет те же действия и ограничения, не создавая отдельного контракта.
